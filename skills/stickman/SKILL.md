# /stickman — stick-figure video in your chosen mode (Jatin's Stickman Skill)

## Step -1 — SETUP CHECK (first run only)
Run `bash ~/.stickman/doctor.sh`. If it is missing or prints FAIL, run `bash ~/.claude/skills/stickman/install.sh` (installs the venv with edge-tts/numpy/scipy, Playwright + Chromium into ~/.stickman, checks ffmpeg/node/python3) and re-run doctor. Needs: node 18+, python 3.9+, ffmpeg.

Engine: `~/.claude/skills/stickman/engine/` (rig `chars.js` incl. real walk cycle `gaitPose`, worlds `env2.js`, props `props.js`, **mode packs `styles.js`**, compositor+captions+finish `main.js`, renderer `render.js`, edge-tts `voice.py`, `stitch.py`, `make.sh`). Mode details + rules: `references/modes.md`. All-modes preview: `modes_preview.jpg`. Worked examples: `example/` (The Seed; old walk code there floats: use `gaitPose`) and the finished projects in the repo's `examples/` folder (Hindi gag dialogue with English captions: `examples/doubt_hindi`; Hindi story: `examples/password_race`).

## Step 0 — MODE (before any story), WITH SAMPLE THUMBNAILS
Thumbnails live in `~/.claude/skills/stickman/thumbs/` (one 540x960 sample per mode: `<id>.jpg`, plus labelled family strips `family_kids.jpg`, `family_minimal.jpg`, `family_dark.jpg`, `family_worlds.jpg`).
1. FIRST show samples: SendUserFile (display "render") the family strips the user needs. If they have not said a family, send all four strips in ONE call (files array), caption "Pick a look".
2. THEN AskUserQuestion (max 4 options per question): family -> exact mode. Families: "Kids / cozy" (candy, cozy), "Minimal line" (classic_light, classic_dark, b1, b2), "Dark & cinematic" (noir, b3 Retro TV, b4 Survival Thriller), "Modern & story worlds" (studio_tech/cinema = A2 Modern Pop, prehistoric, historical, b5 Explainer). Put the strip names in the option text so the user can match them. For a family with >4 modes ask in two questions or use Other. For historical ask era (egypt/rome/castle). Skip anything the user already named. Remember the choice for the session.
3. After the mode is chosen, send that mode's single thumbnail again only if the user asks.
Regenerate thumbs after engine changes: copy engine/web into a scratch dir, run the 14-style test shot (see git history of this skill / modes_preview.jpg) and re-crop.

## Step 0b — LANGUAGE (ask with the mode, same AskUserQuestion round if possible)
Options: English / Hindi (Other = another language supported by edge-tts). Hindi: write script.json in Devanagari (simple spoken Hindi, short sentences, end with । or .), put the voice in `voice.txt` (`hi-IN-MadhurNeural` male narrator, `hi-IN-SwaraNeural` female), everything else is identical: word timings come from edge-tts, captions fall back to NotoDeva automatically, phrase splitting understands । . , ? !. On-screen text made in shots (bubbles, titles) must also be in the chosen language (Poppins has no Devanagari: use font 'NotoDeva' in text()/bubble). English default voice `en-US-AndrewNeural` (male) / `en-US-JennyNeural` (female story). Offer BOTH languages as two builds of the same story when asked (reuse shots.js, only script.json + voice change; re-run stitch, re-check bubble widths, re-time `L('word')` cues that use English words by sentence-relative times).

## Step 0c — CAST TYPE
Ask (AskUserQuestion, send the matching thumbnails first): (1) Stick figures (default), (2) Human figures (`thumbs/humans.jpg`: kids, teacher, woman, grandpa, grandma...), (3) Animal figures (`thumbs/toons.jpg`: panda, bear, cat, bunny, robot), (4) Mixed: humans AND animals as separate characters in the same video (e.g. a human kid with a panda friend; stickmen can also join). Mixed = each role is either a human or an animal, never a half-human half-animal; ask which role is which after the story is chosen. (Animal-headed humans exist in the engine as a legacy extra; do not offer them unless the user asks.)
API (engine/web/): `drawActor(ctx,o)` dispatches by o.human | o.species | stickman. Humans: `{human:'teacher'|'chintu'|'mira'|'woman'|'grandpa'|'grandma'|'boy2'|'girl2', ...}` walking `walker(x0,x,s,humanGait(name))`; animals: `{species:'panda'|'bear'|'cat'|'bunny'|'robot'}` walking `walker(x0,x,s,TOON_GAIT)`; add a person/animal = one entry in HUMANS / TOON_SPECIES. All share arms IK + prop callback, face {eyes,mouth,look,browAng}, talk, hat. `drawCast(ctx,[...])` depth-sorts. Stages with named places + real sizes: `STAGES.cricket|classroom|street` (stage.js). Animals are smaller than humans: scale animals with S.px(y, ~0.9 m) / 0.9 unit so a panda friend reaches a kid's waist/shoulder.
READ references/director-brain.md before writing shots. Views: front / `view:'3q'` / side (auto with walker()) chosen per beat (section 3b); animals walk like real animals (quadruped walk, trot, hop) in side view.

## Step 1 — STORY (read references/story-formula.md first)
1a. Ask how to get the story (AskUserQuestion): (1) "Pick from 4 pitches" (2) "Use a reference video" (user pastes a link or file: run the Skill `anthropic-skills:watch` or `baoyu-youtube-transcript` to get transcript + frames, then write the story beats in your OWN words adapted to the chosen mode/cast; never copy the video's footage, characters or exact script) (3) "I will give story hints" (user types a premise, characters, twist; you expand it into the pitch format and confirm before building). Skip if the user already supplied a story/video/hints.
1b. Pitches: 4 options (titles in the chosen language) in this format: HOOK (what is on screen at second 0) / ENEMY or obstacle / 3 ESCALATION beats / TWIST payoff. Prefer action-comedy, chase, power-gone-wrong, rivalry, survival; cozy modes still need hook + twist. Narrative modes: setup->escalation->payoff; explainer modes: 5-stage arc. ~11-13 sentences, ~35-55 s, simple visible actions that fit the available stages.
After the story is chosen write a one-page beat sheet (sentence -> place -> actors -> action -> contact) and use it for the shot cards.

## Step 2 — BUILD (folder ~/stickman_projects/<name>/)
1. mkdir -p <name>/web <name>/audio; copy `engine/web/*` (incl. fonts/) to web/, and `engine/{render.js,voice.py,stitch.py,make.sh}`; set make.sh output name.
2. script.json (hook first, payoff last). `~/.stickman/venv/bin/python voice.py` (retries/validates) then `python3 stitch.py` -> audio/vo.wav + web/words.js (WORDS with `ph` phrase ids, SENT, VO_END). Adjust GAP list length to sentence count.
3. web/shots.js: first line `useStyle('<mode id>')`; then helpers (copy from example: shot(), Wt(), handheld) and one `shot(i,'whip'|'cut',fn)` per sentence. Use `BG(ctx,t,cam,{...})` for the world, `ACTOR({...})` for the mode's default costume, `walker(x0,x,s)` for ALL walking (returns legs/arms/bob/lean AND flip so legs always follow the direction of travel; merge with Object.assign into drawStick opts; never set flip against the direction of motion = moonwalk), IK arms/prop callbacks (umbrella, seed, can), `bubble`, `burst`, `sparkle`, `rain`, flood/boat/etc in props.js, `drawPresenter` + `sceneText` for b5/b1/b2. Read references/modes.md for the mode's rules (setting changes, hooks, action cards...).
4. Audio: copy `example/audio.py`, rewrite cues (ambience bed, foley at contact, punctuation; mood by mode: dark modes = low drones/heartbeat, kids = plucks/chimes).
5. Stills first (follow director-brain.md section 5; render.js prints `OVERLAP t=..` when two actors overlap >25%: fix spacing/draw order before rendering; keep paused/frozen actors out of the hero's lane, hero never walks through or reaches across another actor): `node render.js stills 0.5,3,6,...` -> ffmpeg xstack contact sheet (scale 360:640) -> LOOK; check walking frames show planted feet, no overlap/cut-off/long bubble tails.
6. Render: `./make.sh` in background (6 workers ~3 min); wait with Monitor until-loop, never sleep-poll. NEVER ctx.filter blur. Re-encode a ~30 MB copy (`-crf 22`) for sending.
7. Check a contact sheet of the final mp4, deliver with SendUserFile, say what was not checked (audio). Never post to Instagram unless asked.

## Optional — two characters talking + English captions on a Hindi (or any) voice
- Put one voice line per sentence in script.json and a `speakers.json` like `["A","B","A",...]` (voice.py gives speaker B a higher pitch, +8% rate; same edge-tts voice).
- Put the English caption for each sentence in `caps_en.json` (same length as script.json). After `python3 stitch.py` run `python3 make_en.py`: it spreads the English words over each sentence's time span and keeps the original-language timings in `WORDS_HI` (use them for action cues, e.g. `WORDS_HI.filter(x=>x.line===i)[k].s - SENT[i][0]`). audio.py should read `WORDS_HI` too.
- `classic_grey` mode = soft grey studio, best for two-character gag dialogues; put captions at y 1745 below the feet and effect labels above heads.
- Optional `gaps.json` = per-sentence pause list (default 0.3 s).
- See `examples/doubt_hindi` in the repo for a complete working project.

## Lessons (read before building)
1. Read all sentences as one beat sheet before voice.py (story consistency). 2. Fix every CROP warning from `render.js stills`. 3. Keep animals big enough to read. 4. Target under 50 s. 5. In audio.py `A(i,k)` is ABSOLUTE time: never add `sh[i]`. 6. Never `pkill` the build or `rm seg/*` inside a build command; make.sh clears old segments itself. 7. If a render already produced all `seg/shot_NN.mp4`, concat + mux them instead of re-rendering. 8. Look at one contact sheet (start and middle frame of every shot) plus 2-3 full-size frames before sending.
